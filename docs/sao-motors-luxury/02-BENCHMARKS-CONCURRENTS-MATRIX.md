# 02 — Benchmarks · Concurrents · Feature Matrix

## Méthodologie

- Sources : sites officiels, presse, LinkedIn, Facebook, DataReportal  
- Scoring interne (0–5) utilisé pour **patterns**, pas pour un classement public « meilleur site »  
- Critères : UX, UI, Conversion, SEO, Perf (approximatif), Mobile, Confiance, Contenu, Features, Local, A11y

## A. Benchmarks internationaux (références UX, pas partenaires)

### A1. Bosch Car Service (réseau mondial)

| Champ | Détail |
|-------|--------|
| URL | https://www.boschcarservice.com/ |
| Type | Réseau ateliers multi-marques |
| Points forts | Booking structuré (service → véhicule → atelier → créneau) ; confiance marque ; diagnostic comme argument |
| Points faibles pour SAO | Trop corporate ; pas adapté WhatsApp-first Afrique ; pricing parfois opaque hors marchés matures |
| Opportunité SAO | Reprendre le **flow en étapes** ; garder confirmation humaine (pas auto-booking plein) |

**Pourquoi ça marche :** réduit la charge cognitive (« quel service ? » → « quel véhicule ? » → « quand ? »).

### A2. YourMechanic (USA)

| Champ | Détail |
|-------|--------|
| URL | https://www.yourmechanic.com/ |
| Type | Mécanicien à domicile |
| Points forts | Quote upfront ; parcours 1-2-3 ; garantie claire ; mobile |
| Points faibles | Modèle métier différent (mobile mechanic) |
| Opportunité SAO | Transparence du devis + diagnostic comme produit |

### A3. Constructeurs premium (Mercedes, BMW, Porsche, Lexus, Tesla)

| Pattern utile | Pattern à éviter |
|---------------|------------------|
| Photographie cinéma, typographie forte, beaucoup d’espace | Over-design sans CTA atelier |
| Configurateurs / storytelling produit | Copier un site constructeur pour un garage |
| Confiance institutionnelle | Promettre un niveau « dealership » sans moyens |

**Pour SAO :** emprunter la **sobriété premium** (noir, blanc, métal, photo réelle), pas le configurateur Tesla.

### A4. Constructeurs chinois (BYD, Geely, Chery, MG, GAC)

| Pattern utile | Note |
|---------------|------|
| Pages SAV claires (garantie, pièces, entretien) | BYD SN : https://www.byd.com/sn/support/service |
| FAQ EV (batterie, autonomie, pièces) | Geely BF Geometry |
| Ton « technologie accessible » | À adapter sans se prétendre concession |

### A5. ChinaDrive (Bénin) — proche du positionnement

| Champ | Détail |
|-------|--------|
| URL | https://chinadrivebj.com/about |
| Type | Concessionnaire véhicules chinois + SAV |
| Positionnement | BYD, Geely, Chery, MG, Haval + EV |
| Opportunité SAO | Même narratif « chinois + EV » mais en **atelier indépendant**, pas showroom vente |

## B. Benchmarks Afrique de l’Ouest

### B1. PROS-MOTORS C.I — Abidjan ⭐ référence conversion régionale

| Champ | Valeur |
|-------|--------|
| URL | https://www.pros-motors-civ.com/ |
| Pays / ville | Côte d’Ivoire / Cocody |
| Type | Garage premium indépendant |
| Positionnement | « Entretien sans mauvaise surprise » ; alternative concessionnaire |
| Services | Quick service, entretien, tôlerie, clim, pièces, lavage, assistance 24/7 |
| CTA | WhatsApp + Appel ; formulaire → WhatsApp |
| Prix | Forfaits affichés (Bronze/Argent/Or) + taux horaires |
| Process | Contact → Diagnostic 20 points → Réparation → Restitution |
| Points forts | Clarté, WhatsApp-first, preuves (m², garantie 2 mois), mobile |
| Points faibles | Claims chiffrés à prendre avec précaution ; peu de SEO long-tail visible |
| Opportunité SAO | Même architecture conversion, **spécialisation chinoise/EV** en plus, photos atelier BF |

**Pourquoi ça marche :** chaque section a une fonction (rassurer / convertir). Pas de fluff.

### Décisions feature (pourquoi)

| Feature | Verdict | Pourquoi |
|---------|---------|----------|
| WhatsApp | Utile MVP | Canal n°1 Afrique de l’Ouest ; preuve PROS-MOTORS |
| Calendrier live | Prématuré | Charge ops atelier ; risque no-show ; Bosch le justifie par réseau |
| Prix publics complets | Optionnel | PROS le fait ; risque litige si pièces variables — préférer « à partir de » ou devis |
| Espace client | Prématuré | ROI faible avant volume |
| Blog | Plus tard P1 | SEO long terme ; pas bloquant conversion jour 1 |
| Dark mode | Inutile MVP | Coût a11y/design ; marque = light premium technique |
| Multilingue | Prématuré | Français suffit pour cible Ouaga premium |

## G. Synthèse : ce que SAO doit emprunter / rejeter

### Emprunter

1. WhatsApp-first (PROS-MOTORS)  
2. Process 4 étapes (PROS / Bosch)  
3. FAQ EV (Geely BF)  
4. Équipe nommée (Technik)  
5. Spécialisation claire (ChinaDrive / Diallo Toyota pattern)  
6. Booking **demande** (GIG) plutôt que calendrier plein  

### Rejeter

1. Compteurs fantômes (CarSos « 0 »)  
2. Stock photos garage US  
3. Template « Auto Repair » WordPress générique  
4. Claims « toutes marques partout en Afrique »  
5. Site constructeur sans CTA atelier  
6. Formulaires de 20 champs  
7. Prix inventés  
8. Partenariats inventés
